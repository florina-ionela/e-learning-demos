People Services Arcade

REQUEST STREAM

Route every request. Keep people moving.

Employee requests are streaming into the help desk. You are on duty: send each request to the right channel before it reaches the bottom.

How to play

  • Read the request, then send it to one of the four destinations below.
  • Mouse or touch: select a request, then select a destination.
  • Keyboard: use Tab to reach a request and press Enter to select it, then Tab to a destination and press Enter. Or press 1 to 4 to route the selected request (or the lowest one if none is selected).
  • Press P or the Pause button at any time.
